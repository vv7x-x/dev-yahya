# موقع يحيى رضا - مطور مواقع وبوتات 🚀

## وصف الموقع
موقع portfolio احترافي بتصميم VS Code مع تأثيرات ثلاثية الأبعاد متقدمة ودعم كامل للغة العربية.

## 🎯 المميزات
- ✨ تصميم VS Code مطابق تماماً
- 🎨 تأثيرات ثلاثية الأبعاد باستخدام Three.js
- 🚀 حركات متقدمة باستخدام GSAP
- 📱 تصميم متجاوب لجميع الأجهزة
- 🌙 تصميم داكن احترافي
- 🔤 دعم كامل للغة العربية

## 🚀 طرق تشغيل الموقع محلياً

### 1️⃣ **Python (الأسهل والأسرع)**
```bash
# انتقل إلى مجلد الموقع
cd /path/to/website/folder

# Python 3
python3 -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# ثم افتح: http://localhost:8000
```

### 2️⃣ **Node.js**
```bash
# تثبيت http-server (مرة واحدة فقط)
npm install -g http-server

# انتقل إلى مجلد الموقع
cd /path/to/website/folder

# تشغيل الخادم
http-server -p 8000

# ثم افتح: http://localhost:8000
```

### 3️⃣ **VS Code - Live Server**
1. ثبت إضافة **Live Server**
2. افتح مجلد الموقع في VS Code
3. انقر بالزر الأيمن على `index.html`
4. اختر **"Open with Live Server"**

### 4️⃣ **XAMPP/WAMP/MAMP**
1. ثبت XAMPP أو WAMP أو MAMP
2. انسخ ملفات الموقع إلى مجلد `htdocs` (XAMPP) أو `www` (WAMP)
3. شغل Apache
4. افتح: `http://localhost/website-folder-name`

### 5️⃣ **PHP Server البسيط**
```bash
# انتقل إلى مجلد الموقع
cd /path/to/website/folder

# تشغيل PHP Server
php -S localhost:8000

# ثم افتح: http://localhost:8000
```
